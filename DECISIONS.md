# DECISIONS.md (Черновик)


### 1. Источник датасета GTZAN
* **Проблема:** Оригинальный канадский сервер (`opihi.cs.uvic.ca`) регулярно падает с `TimeoutError`, а популярное зеркало на Hugging Face недавно было закрыто автором настройками приватности (ошибка `401 Unauthorized`).
* **Решение:** Использовать зеркало на Kaggle (`andradaolteanu/gtzan-dataset-music-genre-classification`).

### 2. Обработка битых файлов
* **Проблема:** Файл `jazz.00054.wav` в датасете GTZAN исторически поврежден и вызывает краш при попытке чтения через `torchaudio`.
* **Решение:** Трек жестко закодирован на исключение (пропуск) на этапе индексации аудиофайлов.
